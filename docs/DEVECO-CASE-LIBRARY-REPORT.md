## 新增高收益轮（23–31）实测结论

- 抽样 23/24/27 **全部显著高于 437 地板**（3,123/7,521/10,418），设计验证成立——审查/大重构/数据审计类轮次结构性产出大 diff 与大文件处理输出。
- 27 轮（10,418，4 次压缩）揭示上限规律：模型不会整 dump 294KB books.json（那会触发 ~73k 的 cat 压缩），而是写 node 脚本分段处理、只打印统计与样本（每次 19–20KB→~4.5k saved）。**大文件杠杆只在任务真需要逐条读全量时才打满**；即便如此 24× 地板。
- 实测发现 `node -e` 等未识别命令的输出**也会被压缩**（27 轮两处各 ~4.5k），比"仅识别命令名才压缩"的文档结论更激进。
