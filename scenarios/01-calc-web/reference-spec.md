# 网页计算器应用 — 功能规格

**目标**：一个单页网页计算器（HTML+CSS+JS，无框架、无后端），浏览器可直接打开使用。

## 用户故事
### US1 基础四则运算（P0，必做）
- 用户点击数字按钮和运算符按钮，输入两个数并得到结果。
- 支持的运算符：＋ － × ÷，等号 = 计算结果，清除 C 重置，退格 ⌫ 删除最后一位。
- 结果按 10 位有效数字格式化；除以 0 显示"错误"而不是崩溃。

### US2 连续运算与表达式（P1）
- 上个结果可作为下一次运算的第一个操作数（连续计算）。
- 顶部输入表达式区实时显示当前输入（如 "5 + 3"），底部显示当前操作数。

### US3 小数、百分号、正负号（P2）
- 支持小数点输入（防止重复小数点）；百分号把当前数转为百分比；± 切换正负。

## 约束
- 纯前端，单 index.html（可内嵌 CSS/JS），无外部依赖、无网络请求。
- 深色主题；按钮至少 44px 可点区域；移动端优先、响应式。
- 代码须通过 `node --check` 语法检查；用无头浏览器（如 `puppeteer` 或系统 chrome）验证点击 1+2= 得 3、7*8= 得 56、8÷2= 得 4、5-3= 得 2。

## 验收
- 打开 index.html 可交互；上述四则运算各出现正确结果；除零显示"错误"不崩溃。
- `node --check index.html`（内含 JS 时用提取脚本）通过。
