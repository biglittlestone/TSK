# 网页计算器应用 — 功能规格（v2，行为级）

**目标**：一个单页网页计算器（HTML+CSS+JS，无框架、无后端），浏览器直接打开即可使用。行为规格见下，实现须逐条满足。验收以「行为测试向量」一节为准——凡未在向量中列出的行为，只要满足交互直觉即可。

---

## 0. 总体要求
- 纯前端，单 `index.html`（可内嵌 CSS/JS）。**无外部依赖、无网络请求、无 `<script src>` 外链**。
- 深色主题；按钮可点区域 ≥44×44px；移动端优先、响应式（375px 到桌面 1280px 均可用）。
- 全部代码须通过 `node --check` 语法校验；最终用一个**真实无头浏览器**（系统 chrome 或 puppeteer）逐条验证行为向量并截图。

---

## 1. US1 — 基础四则运算（P0，必做）
- 用户点击数字按钮和运算符按钮，输入两个操作数并得到结果。
- 支持的运算符：**＋(加) －(减) ×(乘) ÷(除)**；`=` 计算结果；`C` 全清重置；`⌫` 退格删除最后一位输入。
- 结果按 **10 位有效数字**格式化（科学计数法仅当指数 ≥10 或 ≤-9 时采用，如 `1.234567890e+11`）。
- **除以 0 显示「错误」而非崩溃**；错误态下任何数字键重新开始新运算，`C` 清空。
- 连续除 0（如 5÷0= 后再 ÷0=）保持「错误」。

## 2. US2 — 连续运算与表达式（P1）
- 上个结果可作为下一次运算的第一个操作数（连续运算语义：`5 + 3 = 8`，再按 `+` 输入 `2 =` 得 `10`）。
- **顶部表达式区**实时显示当前输入序列（如 `5 + 3`）；**底部显示区**显示当前操作数或中间结果。
- 连续按运算符：`5 + + + 3 =` 视作 `5 + 3 = 8`（运算符替换）。
- 结果后再按数字，开始新的独立运算；结果后再按运算符，把结果作为第一操作数继续。

## 3. US3 — 小数、百分号、正负号（P2）
- **小数点** `·`：支持输入，防重复（`1.5` 后再按 `·` 仍为 `1.5`）。
- **百分号 `%`**：把当前操作数转为百分比（`200 % → 2`，即 `÷100`）。作为运算符参与时先取百分数：`50 × 20 % = 10`。
- **±（正负切换）**：切换当前操作数符号（`5 ± → -5`；`-5 ± → 5`）；对表达式中的当前段生效。

## 4. 键盘与无障碍
- 物理键盘：`0-9`、`.`、`+ - * / `、`=`(或 Enter)、`Backspace`(退格)、`Escape`(清空)、`p`(百分号)、`n`(±)。
- 每个按钮有 `aria-label`；用 `<button>` 而非 div；焦点可见。

## 5. 多语言标签（i18n）
| 控件 | zh | en |

| 加 | ＋ | + |
| 减 | － | − |
| 乘 | × | × |
| 除 | ÷ | ÷ |
| 等于 | = | = |
| 清除 | C | C |
| 退格 | ⌫ | ⌫ |
| 百分号 | ％ | % |
| 正负 | ± | ± |

界面语言跟随浏览器 `<html lang>`，默认中文；切 en 时按钮 `aria-label` 与错误文案切换为英文。

## 6. 精度与格式化规则
- 有效数字 10 位；去除尾随无意义 0（`2.500 → 2.5`）；整数不带小数（`8 → 8`）。
- 超大/超小用科学计数法（指数规则见 US1）。
- 浮点中间结果按「显示 10 位有效数字」的字符串参与下一次运算（避免浮点误差累积如 `0.1+0.2`）。

## 7. 响应式与主题
- 深色背景 `#1e1e24` 系；按钮圆角 12px；操作符列（右）用强调色 `#ff9f43`，等号 `#e8734a`，数字 `#2a2a33`。
- 375px：单列竖排，网格 5 行（显示区 + 4 行按钮）；≥768px：横向留白居中，最大宽 420px。
